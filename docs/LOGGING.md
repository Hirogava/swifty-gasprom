# Логирование в Swifty Gasprom Backend

## Обзор

В проект добавлено комплексное логирование на основе `logrus` с поддержкой JSON-формата и ротации файлов.

## Конфигурация

### Переменные окружения
- `LOG_LEVEL` - уровень логирования: `debug|info|warn|error` (по умолчанию `info`)
- `LOG_TO_CONSOLE` - выводить логи в консоль: `true|false`

### Настройки логгера
- **Формат**: JSON с временными метками
- **Файл**: `./logrus.log`
- **Ротация**: 10MB, 5 бэкапов, 30 дней хранения, сжатие включено
- **Консоль**: опционально (через `LOG_TO_CONSOLE`)

## Уровни логирования

### Debug
- Детальная информация о процессе
- Параметры запросов
- Состояние БД
- Токены (без секретов)

### Info
- Важные события
- Успешные операции
- Запуск/остановка сервисов

### Warn
- Потенциальные проблемы
- Неверные запросы
- Истёкшие токены

### Error
- Ошибки выполнения
- Сбои БД
- Критические проблемы

## Структура логов

Все логи в JSON формате с полями:
```json
{
  "level": "info",
  "msg": "Login successful",
  "time": "2024-01-15 10:30:45",
  "user_id": "123e4567-e89b-12d3-a456-426614174000",
  "ip": "192.168.1.100",
  "method": "POST",
  "path": "/api/v1/login"
}
```

## Мониторинг

### Ключевые метрики для мониторинга:
- Количество ошибок аутентификации
- Время отклика БД
- Частота использования эндпоинтов
- Ошибки миграций
- Неудачные попытки входа

### Алерты:
- `level=error` - критические ошибки
- `level=fatal` - остановка сервера
- Высокая частота ошибок аутентификации
- Проблемы с БД

## Использование

### Запуск с логированием в консоль:
```bash
LOG_LEVEL=debug LOG_TO_CONSOLE=true go run ./cmd
```

### Запуск только в файл:
```bash
LOG_LEVEL=info LOG_TO_CONSOLE=false go run ./cmd
```

### Просмотр логов:
```bash
tail -f logrus.log | jq '.'
```
